# AI Hotel Precheck Assistant: HW3 sample

Course project (SPbU, "AI systems life cycle"). The data here are **synthetic** (generated by script, seed 2026); no real guests or hotels.

Files:
- `gen_sample.py`: generates `raw_cases.jsonl` (60 booking/hotel-reply cases with gold labels).
- `check_sample.py`: quality checks; writes `prepared_labels.csv` (with train/val/test split by group) and `quality_report.json`.
- `v1_first_run/`: output of the first generator version, kept to document the problems found.

Run: `python gen_sample.py` then `python check_sample.py` (Python 3, standard library only).
